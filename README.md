# Bolonha e Milano

Jogo de estratégia econômica medieval em Java, jogado pelo console. O jogador comanda uma cidade da Itália medieval, começando no ano de 1400 com o título de Cavaleiro.

> Projeto em desenvolvimento (SPOTDES). Ainda não há economia: por enquanto existem apenas o menu e a criação do jogador e da cidade.

## Etapas

- **Etapa 1**: estrutura inicial, classes Main e Menu.
- **Etapa 2**: classes Jogador e Cidade, novo jogo e status da cidade.
